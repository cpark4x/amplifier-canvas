Browser Dev Mode — How I Build UI Now

1
Start browser dev server
Serves just the React renderer. No Electron, no native modules.
Mock API provides fixture data (projects, sessions, files).
npm run dev:browser
2
Edit React components
Change styles, layout, components, interactions.
Vite hot-reloads instantly — no rebuild needed.
instant HMR
3
Screenshot & verify in browser
I use browser automation to take screenshots, click through
flows, check multiple viewports. I can see what I built.
looks wrong? → go back to 2
4
Verify Electron build
Confirm the same code works in the real Electron shell.
The mock is a no-op in Electron — preload bridge takes over.
npm run build
5
Commit
UI verified visually + Electron build passes. Ship it.
