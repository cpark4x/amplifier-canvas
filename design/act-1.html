Act 1 — Getting Started

Four scenes: first launch through returning user. Sidebar + terminal only — no viewer panel.

Job to be done: Get from zero to a running Amplifier session inside Canvas with the minimum possible friction.
You’ve heard about Canvas. Maybe you’re skeptical — you already use Amplifier from the terminal and it works fine. You download it, open it. The window appears. It’s warm, quiet, mostly empty. There’s nothing to learn because there’s almost nothing on screen. The only question is: do you create a project? The whole act takes under a minute. By the end, Amplifier is running and you haven’t left Canvas.

Scene 1.1 — Welcome

You open Canvas for the first time. The window is clean — a narrow sidebar on the left shows “No projects yet” with an “Add project” button at the bottom. The main area is warm off-white with a centered message: “Welcome to Canvas — Your workspace for Amplifier sessions, files, and previews.” One button: “Create your first project →.”

Canvas’s personality is established before anything functional happens. Warm, not cold. Inviting, not overwhelming. The sidebar is visible but empty — foreshadowing the structure that fills in later. The single call-to-action means zero decision paralysis.

Scene 1.3 — Add Project

You click “Add project.” A modal appears over a subtle overlay. “Add Project” at the top. Two tabs: New and Existing. On the New tab: project name, location, and bundle choice. On the Existing tab: Canvas has already discovered projects on your machine that have Amplifier sessions. Select one, then choose to start a new session or resume an old one.

This is the only configuration moment in the entire onboarding. The choices are few and obvious. The modal is small, centered, and feels like a quick aside — not a commitment. The “Existing” tab signals Canvas respects your existing workflow.

Scene 1.4 — Session Started

You hit create. The sidebar immediately shows your project name as a label (“CANVAS-APP”) with one session below it: amber dot, bold text, “just started” in amber. The main area is a full-width terminal. The Amplifier CLI banner appears: session ID, project name. A blinking amber cursor waits for your first prompt. Three things happen simultaneously: the project exists, a session is running, and the terminal is live.

No intermediate screens, no “setting up your workspace” spinner. The session-first sidebar design is already visible — the project name is a label, not a destination. The session is the primary object. The pane title reads “main · canvas-app” — session first, project second. You’re inside Amplifier now. Canvas got out of the way.
